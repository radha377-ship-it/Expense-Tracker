# Expense & Wealth Tracker

A responsive, client-side web application for tracking daily expenses, income streams, multi-currency accounts (AED and USD), encrypted bank statements (CSV/PDF), and multi-currency fixed deposits.

## Key Features
* **Multi-Currency Accounts**: Bank checking in AED and Credit Card in USD with automated exchange conversion (1 USD = 3.6725 AED).
* **Dual Income & Expense Parsing**: Automatic detection of deposits and debits from uploaded CSV and password-protected PDF bank statements.
* **Fixed Deposit Portfolio**: Track term deposits in AED, USD, EUR, and GBP with real-time yield calculations and maturity countdowns.
* **Duplicate Detection Engine**: Fingerprint-based duplicate transaction checking with one-click resolution.
* **Interactive Chart.js Analytics**: Responsive doughnut and pie charts of category spending.
* **Offline & Private**: 100% browser-based with `localStorage` persistence — no financial data leaves your device.
* **Google Drive Database Backup**: Export clean CSV ledgers compatible with Google Sheets and Excel.

## Getting Started
Simply open `index.html` in any web browser or deploy it to GitHub Pages / Netlify.
